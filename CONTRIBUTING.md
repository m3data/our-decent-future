# Contributing to Our Decent Future

Thank you for your interest in contributing to Our Decent Future! This project is focused on collaborating with people and communities to design future systems for living.

## How to Contribute

### Content Contributions

We welcome contributions that align with our principles and values:

1. **Fork the repository** - Create your own fork of the project
2. **Create a branch** - Make your changes in a new git branch
3. **Make your changes** - Add or update content that contributes to the vision
4. **Submit a pull request** - Submit your changes for review

### Types of Contributions

- **Ideas and Visions** - Share your thoughts on future systems
- **Documentation** - Improve or expand existing documentation
- **Principles and Values** - Suggest refinements to our guiding principles
- **Resources** - Add links to related projects, thinkers, or initiatives

### Guidelines

- Keep contributions constructive and aligned with project values
- Write clearly and concisely
- Respect the collaborative nature of the project
- Be open to feedback and discussion

### Content Style

- Use Markdown formatting for all content
- Keep paragraphs concise and readable
- Use headings appropriately to structure content
- Include relevant links and references where applicable

## Running the Site Locally

This is a Jekyll-based site. To run it locally:

```bash
# Install dependencies
bundle install

# Run the Jekyll server
bundle exec jekyll serve

# Visit http://localhost:4000/our-decent-future in your browser
```

## Questions?

If you have questions about contributing, feel free to open an issue for discussion.

## Code of Conduct

Be respectful, inclusive, and mindful of diverse perspectives. This project embraces:
- Diversity and inclusion
- Empathy and patience
- Collaborative spirit
- Authentic and respectful communication

Thank you for contributing to a better future!
